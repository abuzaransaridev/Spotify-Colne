# Spotify Clone

This is a Spotify Clone website created using HTML and CSS.

The main goal of this project was to practice frontend development and recreate the look and layout of a modern music streaming platform.

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Remix Icons

## Features

- Navigation bar
- Sidebar
- Search section
- Playlist section
- Music player
- Artist section
- Dark theme UI
- Responsive layout

## Project Preview

A Spotify-inspired user interface with a clean and modern dark design.

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.
